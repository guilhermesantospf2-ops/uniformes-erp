# Uniformes ERP — Gestão Completa para Confecção & Estamparia

Sistema operacional e financeiro completo para indústrias de uniformes profissionais, esportivos e escolares.

## 🚀 Funcionalidades
- **Gestão de Pedidos com Radar de Prazos**: Contagem regressiva dinâmica com alertas visuais por cores (verde, azul, âmbar, vermelho piscante).
- **Ficha Técnica & Proposta Comercial A4**: Geração e impressão com mockups de estampa e tabela de medidas.
- **Motor de Encaixe DTF (Nesting Engine)**: Otimização de aproveitamento de rolo de impressão.
- **Kanban Visual de Produção**: Acompanhamento de corte, estamparia, costura e expedição com drag-and-drop.
- **Nuvem em Tempo Real (Firebase Firestore)**: Sincronização multi-dispositivo e persistência resiliente offline-first.
- **Módulo Financeiro & Balancete**: Controle de margem de contribuição, custos de tecido e conciliação.

## 🛠️ Tecnologias
- HTML5 Semântico
- Vanilla CSS Moderno (Design System Dark Mode Corporativo)
- JavaScript Puro (Modular, sem dependência pesada de build)
- Firebase Firestore Realtime Compat SDK
